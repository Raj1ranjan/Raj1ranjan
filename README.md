## Engineering work & experiments

RBRAW Burst ProcessingPython · RawPy · OpenCV

Developed a Python-based experimental pipeline using RawPy and OpenCV to process multiple DNG photographs.

- Processed 16-bit linear RAW image data.
- Implemented image alignment using ECC-based registration.
- Experimented with multi-frame fusion for noise reduction.
- Evaluated image quality using noise measurements and signal-to-noise comparisons.

BPBayer Image ProcessingColour planes · Motion-aware fusion

Built an experimental Bayer-processing pipeline with separate colour-plane processing and motion-aware fusion.

- Worked with individual Bayer colour planes.
- Tested alignment and fusion on static and moving scenes.
- Developed noise-aware sample rejection.
- Evaluated fusion quality against individual input frames.

**i**

**Experimental results:** Approximately 1.75× SNR improvement in a tested fusion scenario, with around 93.5% rejection of injected moving-object samples in a motion-challenge test.These are results from controlled experiments, not universal performance claims.
